⚙️ Configuración Rápida

🚀 Comenzar

Opción 1 (Más Fácil): Abre pse-welcome.html en tu navegador y prueba el flujo completo de PSE y recargas.

Opción 2 (Preview): Abre preview.html para ver la interfaz con datos de prueba y simular recargas.

📦 Instalación de Automatización

Paso 1: npm install

Paso 2: npm start

Se abrirá el navegador y automatizará todas las recargas

🛠️ Archivos Principales

• pse-welcome.html - Sistema completo PSE + Nequi (👈 Usa este)
• preview.html - Interfaz visual para pruebas
• src/index.js - Script de automatización Node.js
• src/data.js - Datos de prueba
• DATOS_RECARGA.md - Guía de configuración de números
• GUIDE.md - Documentación completa
